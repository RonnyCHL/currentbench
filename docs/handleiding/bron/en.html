Safety first

{{NAAM}} controls a real power supply. A wrong setting can damage a circuit, and a bug in a program or a loose USB cable can always happen. Use the program at your own risk.

The real protection is in the supply

The current limit on the supply always works, even if the program is closed or has crashed. So always set it to a suitable value, and never rely on the program alone. If the program goes away while the output is on, the output simply stays on.

Four habits

  1. First the current limit, then the voltage, and only then turn the output on.
  2. With anything new, start with a low current limit, for example 0.1 A, and watch whether the supply is limiting.
  3. Check the polarity: red terminal plus, black terminal minus.
  4. Turn the output off when you are done, and before you connect or disconnect anything.
Emergency stop

The Esc key turns the output off immediately, in every window of the program. Everything that is running stops too.

How to read this manual: buttons appear in the text as [[Gereedschap]], [[blauw:Instellen]], [[groen:Opslaan]] or [[rood:Stop]]. The example screens were made with a simulated supply; you will see your own values.

Installing and starting

You need Windows 10 or 11 and Python 3.10 or newer, from python.org. When you install Python, tick Add python.exe to PATH.

  1. Unpack the program into its own folder, for example in Documents.
  2. Open that folder in File Explorer, type cmd in the address bar and press Enter.
  3. Type py -m pip install -r requirements.txt once and press Enter.
  4. Start the program with py korad_paneel.py.

The first time, the program follows the Windows language. If that is not Dutch or German, it starts in English. You choose the language and the appearance under [[Instellingen]] (chapter {ref:instellingen}).

Trying it without a supply

In the port list at the top right, choose DEMO and click [[blauw:Verbinden]], or start with py korad_paneel.py --demo. The program then restarts with a simulated supply and a small simulated load. The title bar shows DEMO.

The demo does not open any COM port. Readings from the demo are not real and stay in a separate folder, apart from your own projects and measurements.

Connecting to the supply

  1. Turn the supply on and connect the USB cable.
  2. Choose the COM port at the top right. If it is not listed, click the round arrow next to it.
  3. Click [[blauw:Verbinden]]. The dot turns green, the model appears at the top and the meters start running.

On first use, with nothing connected to the terminals, check that the readings match the display of the supply.

Good to know

A COM port can only be used by one program at a time. So first close any other programs that talk to the supply.

If the output was already on when you connected, the program asks whether it should be turned off. Choose Yes if you are not sure what is connected to it.

Which supplies

The program reads the model from the supply and adjusts its range to match. It recognizes the Korad KA and KD series of 30 and 60 V and the identical models from Tenma, Velleman, RND and Stamos. Only the KA3005PS has actually been tested. Supplies with two channels, such as the KA3305P, do not work. The full list is in the README.

An unknown model

If the device answers like a Korad but the program does not know the model, you get a warning. If you choose to connect anyway, you enter the maximum shown on the rating plate. The program never goes above it and remembers it for next time.

Setting the voltage and current limit

  1. Enter the voltage in ((Spanning)). You can use a comma or a point.
  2. In ((Stroomgrens)), enter the most current that may flow.
  3. Press Enter or click [[blauw:Instellen]]. The program sends the current limit first and then the voltage.
  4. Click [[Uitgang aanzetten]]. That button turns green and also turns the output off again afterwards.

The four buttons at ((Geheugen)) recall fixed combinations; the button shows what is stored in it.

Caution

If you want to raise the voltage while the output is on, the program asks first whether that is OK: the higher voltage goes straight to whatever is connected.

Projects and limits

A project is the limit the program guards, with its own color. You see the color on the button at the top and next to the title of every window. Within a project, the program refuses anything above the limit: when setting values, with the memory buttons, in test programs and in battery simulation.

The program starts with one project, {{VRIJ}}, which allows the full range of the supply. Create a separate project with a safe limit for each circuit.

Creating a project

  1. Click [[Projecten]] on the left and click an existing project.
  2. Enter the name, the highest voltage, the highest current and the reason, and choose a color.
  3. Click [[Als nieuw project toevoegen]]. [[groen:Opslaan]] would overwrite the project you clicked.
  4. Click [[blauw:Dit project kiezen]].
@@ projecten | Each project has its own limit, color, memories and guards.

Set the memory buttons and the guards the way you want, then click [[Geheugens en bewaking van nu bewaren]]. When you choose the project, you get those values back.

When the limit is exceeded

The supply can also be set higher from its front panel. If that happens while the output is on, the program turns the output off within one or two seconds and raises an alarm. The alarm stays until you clear it in the status box.

If a new project may go higher than the current one, the program first asks whether everything connected can handle that. A damaged project file is ignored and so can never raise a limit.

The ring meters

The number in the middle is what the supply is measuring now. The white mark on the ring is the set voltage or the current limit. The red section outside the current ring starts just below the current limit: when the ring gets there, the supply is about to start limiting. The red zone on the voltage ring is everything above the project limit.

Usage and current in view

The box at the top right counts the charge (mAh) and energy (Wh) since the counter was last reset. Below that are the highest, average and lowest current over exactly the section shown in the chart. If you zoom in, the box calculates only that section.

The program remembers more than twenty hours of readings. If you want to keep them, start a log.

Guards

With [[Bewaking instellen]] you create up to three rules that the program checks at every reading while the output is on. A rule reads like a sentence: current above 300 mA for longer than 5 s, then output off. You choose current, voltage or power, above or below, the value, how long, and whether the output should turn off or you only want a warning.

@@smal bewaking | Guard rules work alongside the supply's current limit.

Logging and reports

Keeping a log

Click [[Log starten]] at the bottom right and choose a name. Every reading then goes into a CSV file as a line, along with the markers. You can view an old log with [[Log openen]] above the chart.

Creating a report

Zoom the chart in on the section you want to record and click [[Rapport maken]]. Give it a title and, if you like, a comment. The report opens in the browser; with Ctrl+P and Save as PDF you turn it into a PDF.

Battery simulation

On the second row at the bottom, you can make the voltage change slowly, as with a battery running down. Enter the start and end voltage and the duration and click [[Start]].

With R you simulate the internal resistance, in milliohms: the program then keeps setting the voltage to the source voltage minus current times R. This shows whether a circuit keeps working when the voltage sags under load. The simulated battery stops when you set something yourself.

Test programs

A test program is a series of steps the supply runs through automatically. Open the window with [[Testprogramma's]] at the bottom right.

@@ programmas | A test program with steps and expected results.

For each step you choose the transition (step or ramp), the voltage, the current limit, whether the output is on or off, and the duration. You can also enter an expected result: the average current must then be between two limits. At the end you see pass or fail for each step.

After [[groen:Starten]] the program states the number of steps, the duration and the highest voltage, and asks whether it may go ahead. A program that goes above the project limit anywhere does not start. The steps appear as bands in the chart. Esc or the stop button stops it immediately; the output then turns off.

Tools

The [[Gereedschap]] button in the column on the left opens all the tools. Click a tile to open it.

@@ gereedschap | All the tools in one place.

Startup curve

You would rather not put a new circuit straight on full voltage. The startup curve raises the voltage in small steps from 0 and plots the current. A fault then shows up at just a few volts. At the current limit the program stops and the output turns off.

@@ opstartcurve_uitslag | Below the chart, it says in plain language what you can see.

If all goes well, the output stays on at the end voltage. The gray lines are the previous measurements, so you can see what a change does to the curve.

Component tester

The supply as a measuring instrument for a single component. At the top, choose what you are measuring; the drawing shows how to connect it between the terminals. Click [[blauw:Meten]] and confirm that only the loose component is connected. The output turns on briefly with a low current limit and then your own settings are restored.

Loose components only

Never connect a whole circuit during a component measurement.

Current fingerprint and restart counter

A working board starts up the same way every time. The current fingerprint saves that pattern, so at the next start you see right away whether a new board or new firmware differs.

  1. Connect a board you know is good, turn the output on and wait until it has started up.
  2. Click the current fingerprint button on the left, enter a name and save the last start as a new fingerprint.
  3. Turn the output off and on again and add that start to the fingerprint. The more starts, the more realistic the band.
  4. Choose the fingerprint and turn it on.

At every following start, the program tracks the current against the band, and the box with the current shows what percentage falls within it. At 95 percent or more, that counts as good. The current fingerprint only warns; the output stays as it is.

@@ afdruk | A saved current fingerprint.

Restart counter

A board that keeps restarting shows it in the current: a short dip and then back to the normal level. The program counts those dips. If they are regular, the time between them is shown too.

Overnight test and comparing logs

Overnight test

Some faults only appear now and then. The overnight test measures for hours on end and records everything. Enter the duration, the voltage, the current limit and the notification limit and click [[blauw:Start]]. The output turns on and a log starts.

Current peaks, current limiting and an output turning off appear as markers in the chart and, if notifications are on, on your phone. At the end the program creates a report automatically. Keep the computer on for that time and do not let it go to sleep.

Compare logs

Lay two logs over each other, for example the usage before and after a firmware update. Choose measurement A and B, and above the chart choose what you want to see. The table below gives the values and the difference per measurement, also in percentages.

@@ vergelijken_uitslag | Two logs overlaid, with the differences in a table.

Workbook

Everything you do with the program goes into the workbook automatically, so you can find later what you measured and when. Choose a type or enter a search term. Double-click a line to load a log into the chart or open a report. With [[Notitie toevoegen]] you can add something yourself.

@@ werkboek | The workbook puts everything in date order.

Bench mode, Mini window and sound

Bench mode. With F11 the whole screen becomes a display with huge numbers and a large off button. F11 again brings you back.

@@ werkbank | Bench mode is easy to read from a distance.

Mini window. A small window that always stays on top, with voltage, current and an off button. Double-click the numbers to bring back the large window.

Sound. If the supply limits for longer than half a second, you hear a short double beep. You can turn this off under [[Instellingen]].

Spoken notifications. The program can say what is happening. Turn this on under [[Instellingen]] and try it with [[Laat horen]]. If the voice for your language is missing, add it in the Windows settings, under Time & language and Speech.

Phone and notifications

Phone as remote control

  1. Open [[Gereedschap]], then ((Telefoon)), and click [[blauw:Aanzetten]].
  2. The first time, Windows asks whether Python may accept connections. Choose Private networks.
  3. Scan the QR code with your phone. It must be on the same Wi-Fi network.

On the phone you see the meters and the chart, and you can place a marker.

Safe

From the phone the output can only be turned off. Turning it on or changing the voltage is only possible on the computer. The link contains a code that works like a password; with [[Nieuwe code]] old links stop working.

Notifications via ntfy

  1. Install the free ntfy app on your phone.
  2. Make up a long name that nobody can guess, and subscribe to it in the app.
  3. Enter that name under [[Instellingen]], turn the notifications on and click [[Testmelding sturen]].

You get a message on an alarm, when a test program or overnight test finishes, and when the supply becomes unreachable while the output is on. Anyone who knows that name can read your notifications, so treat it like a password.

Settings and your data

Under [[Instellingen]] you choose the language, the light or dark appearance, the sound, the spoken notifications and the notifications on your phone. After you change the language or appearance, the program offers to restart.

@@ instellingen | Language, appearance, sound and notifications in one place.

Where your data is

Everything you create stays on your own computer, in %APPDATA%\CurrentBench. There you will find your projects, logs, reports, test programs and the workbook. [[Gegevensmap openen]] takes you there. Make a backup of it yourself from time to time.

If you want to keep everything next to the program, for example on a USB stick, put an empty file portable.txt next to korad_paneel.py.

Local API

With the local API, scripts can take measurements through the program while it simply stays open. It is off by default; you turn it on under [[Instellingen]]. The local API can only be reached on this computer and requires a code from the settings.

CommandWhat it does
py korad_klant.py standWhat the supply is doing now.
py korad_klant.py zet 5 0.5First the current limit, then the voltage.
py korad_klant.py aan --akkoordOutput on.
py korad_klant.py uitOutput off.
py korad_klant.py actiesAll available commands.

Scripts have the same limits as the buttons. Turning the output on or raising the voltage requires explicit approval, and you always answer questions on the screen yourself.

Closing and the safety net

What happensWhat the program does
Closing with the output onIt asks what should happen: turn the output off and close, leave the output on and close, or stay open. If you leave it on, nobody is guarding it any more.
A bug in the programA running test stops, the output turns off and you get a message. The details are in korad_fouten.log in your data folder.
USB disconnected or supply offIt reports that the connection is lost and stops whatever was running. It can then no longer control the output; the supply's current limit keeps working.
